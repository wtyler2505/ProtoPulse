# The Vision (frozen)

The three founding volumes of the ProtoPulse ground-up redesign, authored
by Tyler and delivered 2026-06-10. **These files are frozen** — they are
the fixed specification reality gets diffed against, not living docs.

- [Volume I — Ground-Up Redesign, Maximal Edition](./volume-1-ground-up-redesign.md)
  — theses, the one-graph architecture, the AI crew, simulation, the
  physical bridge, the build order.
- [Volume II — The Deep Spec](./volume-2-deep-spec.md) — every subsystem
  down to interfaces, algorithms, protocols, and part numbers.
- [Volume III — The Content Layer & Day One](./volume-3-content-and-day-one.md)
  — curriculum tracks, concepts wiki, MCU emulation matrices, community
  mechanics, the Probe enclosure, and the Day One repo / Milestone 1 bar.

## Rules of the road

1. **Never edit these in place.** A silent edit destroys their value as
   the reference point.
2. **Deliberate deviations get an ADR** in [`docs/adr/`](../adr/) —
   what changed, why, and what would revisit it.
3. **Progress against the vision** is tracked in [`ROADMAP.md`](../../ROADMAP.md).
4. If the vision itself genuinely changes, write a versioned amendment
   (a Volume IV, or "Vol II rev B") as a new file here.
