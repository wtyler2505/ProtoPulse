# RC522 RFID reader module — verification note

Added `core:rc522` to `@protopulse/parts`. Pinout **web-verified** — NOT taken from

## Part
- **MPN:** RC522 (NXP MFRC522 13.56 MHz contactless reader)
- **Datasheet:** https://www.nxp.com/docs/en/data-sheet/MFRC522.pdf
- **Function:** 13.56 MHz RFID/NFC reader (MIFARE); SPI (also I²C/UART, but boards
  ship strapped for SPI).
- **Class:** modeled `class: 'ic'`, refPrefix `U`

## Pinout — 8-pin SPI header (verified order)
| Pin | Name | Role | Electrical type (ERC) |
|----:|------|------|-----------------------|
| 1 | SDA | SS/CS — slave select (master-driven) | input |
| 2 | SCK | SPI clock from master | input |
| 3 | MOSI | master out → slave in | input |
| 4 | MISO | slave out → master in | output |
| 5 | IRQ | interrupt request out | output |
| 6 | GND | ground | power_in |
| 7 | RST | reset (master-driven) | input |
| 8 | 3.3V | power supply | power_in |

## Interface / electrical
- **SPI slave:** the MCU is master; SCK/MOSI/SDA(SS)/RST are inputs to the module,
  MISO and IRQ are outputs from it. Up to 10 Mbps.
- **Voltage:** MFRC522 runs 2.5–3.6 V; the module's comms pins are 5 V tolerant, so a
  5 V Arduino works without level shifting (power still 3.3 V).
- The "SDA" label is a carry-over from I²C naming; in SPI mode it is the slave-select.
