# 1602A 16x2 character LCD (HD44780) — verification note

Added `core:lcd1602` to `@protopulse/parts`. Pinout **web-verified** — NOT taken from
Tyler's shared `docs/parts-components-ect.md`. First character-display part; the
canonical 16-pin parallel HD44780 module.

## Part
- **MPN:** 1602A (HD44780U dot-matrix LCD controller/driver)
- **Datasheet:** https://www.sparkfun.com/datasheets/LCD/HD44780.pdf
- **Function:** 16x2 character LCD, 4-bit or 8-bit parallel interface.
- **Class:** modeled `class: 'ic'`, refPrefix `U`

## Pinout — 16-pin parallel header (verified)
| Pin | Name | Role | Electrical type (ERC) |
|----:|------|------|-----------------------|
| 1 | VSS | ground | power_in |
| 2 | VDD | +5 V (4.7–5.3 V) | power_in |
| 3 | V0 | contrast (pot wiper) | input |
| 4 | RS | register select (cmd/data) | input |
| 5 | RW | read/write select | input |
| 6 | E | enable strobe | input |
| 7 | D0 | data bus bit 0 | bidi |
| 8 | D1 | data bus bit 1 | bidi |
| 9 | D2 | data bus bit 2 | bidi |
| 10 | D3 | data bus bit 3 | bidi |
| 11 | D4 | data bus bit 4 | bidi |
| 12 | D5 | data bus bit 5 | bidi |
| 13 | D6 | data bus bit 6 | bidi |
| 14 | D7 | data bus bit 7 (+ busy flag on read) | bidi |
| 15 | A | backlight LED anode (+) | power_in |
| 16 | K | backlight LED cathode (−) | power_in |

## Modeling note — D0–D7 are bidirectional
The 8-bit data bus is genuinely bidirectional: the HD44780's busy flag is read back on
D7, and the controller supports read commands. 4-bit mode uses only D4–D7. Modeled as
`bidi`, not input-only, for ERC correctness. V0 is the analog contrast input (pot
wiper between VDD and VSS). A/K drive the backlight LED (A usually via a series
resistor to +5 V, K to GND).
