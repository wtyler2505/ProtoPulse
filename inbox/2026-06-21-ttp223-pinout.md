# TTP223 capacitive touch sensor module — verification note

Added `core:ttp223` to `@protopulse/parts`. Pinout **web-verified** — NOT taken from
Tyler's shared `docs/parts-components-ect.md`. Fifth Tier-2 sensor; **breaks** the
LM393 comparator pattern — this uses a dedicated Tontek TTP223 touch IC.

## Part
- **MPN:** TTP223 (Tontek single-channel capacitive touch IC)
- **Reference:** https://electropeak.com/learn/interfacing-ttp223-capacitance-touch-sensor-with-arduino/
- **Function:** single capacitive touch pad → digital output.
- **Class:** modeled `class: 'ic'`, refPrefix `U`

## Pinout — verified signals (3-pin)
| Pin | Name | Role | Electrical type (ERC) |
|----:|------|------|-----------------------|
| 1 | VCC | 2.0–5.5 V | power_in |
| 2 | GND | ground | power_in |
| 3 | SIG | push-pull digital out, active-HIGH default | output |

## Behavior / config note
SIG is **push-pull** (no external pull-up needed; connect straight to a GPIO),
**active-HIGH** by default. Two rear solder pads reconfigure it: **A** → toggle mode
(latch on each touch), **B** → invert to active-LOW. 2.0–5.5 V, works on 5 V and 3.3 V
systems alike.
