# MAX7219 LED matrix driver module — verification note

Added `core:max7219` to `@protopulse/parts`. Pinout **web-verified** — NOT taken from

## Part
- **MPN:** MAX7219 (serially-interfaced 8-digit LED display driver)
- **Datasheet:** https://www.analog.com/media/en/technical-documentation/data-sheets/MAX7219-MAX7221.pdf
- **Function:** drives an 8x8 LED dot-matrix (or eight 7-seg digits); SPI-like
  3-wire interface; daisy-chainable.
- **Class:** modeled `class: 'ic'`, refPrefix `U`

## Pinout — modeled 6 unique signals (verified)
| Pin | Name | Role | Electrical type (ERC) |
|----:|------|------|-----------------------|
| 1 | VCC | 5 V | power_in |
| 2 | GND | ground | power_in |
| 3 | DIN | serial data in (MCU MOSI) | input |
| 4 | CS | chip select / LOAD latch | input |
| 5 | CLK | serial clock | input |
| 6 | DOUT | daisy-chain data out → next DIN | output |

## Two-header modeling note
The module has a 5-pin **INPUT** header (VCC, GND, DIN, CS, CLK) wired to the MCU and
a 5-pin **OUTPUT** header (VCC, GND, DOUT, CS, CLK) for cascading. The two share
VCC/GND/CS/CLK; the only distinct extra signal is **DOUT**. We model the 6 unique
signals. To chain: wire this module's DOUT → next module's DIN (share VCC/GND/CS/CLK).
