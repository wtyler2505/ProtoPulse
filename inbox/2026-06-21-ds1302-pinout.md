## Part
- **MPN:** DS1302 (Maxim / Analog Devices "Trickle-Charge Timekeeping Chip")
- **Datasheet:** https://www.analog.com/media/en/technical-documentation/data-sheets/ds1302.pdf
- **Function:** real-time clock/calendar + 31 bytes static RAM, trickle-charge backup
- **Class:** modeled `class: 'ic'`, refPrefix `U`

## Interface — 3-WIRE SERIAL, NOT I²C
The single most important correction: the DS1302 is a **3-wire synchronous serial**
device, **not I²C** (unlike the DS1307/DS3231 family it is often grouped with). The
three signal lines are:
- **CLK (SCLK)** — serial clock, MCU → module (input)
- **DAT (I/O)** — bidirectional serial data
- **RST (CE)** — chip enable, MCU-driven, must be **HIGH** during a transfer (input)

## Pinout — DS1302 module 5-pin header (verified order)
| Pin | Name | Role | Electrical type (ERC) |
|----:|------|------|-----------------------|
| 1 | VCC | module power (2.0–5.5 V) | power_in |
| 2 | GND | ground | power_in |
| 3 | CLK | serial clock (in) | input |
| 4 | DAT | bidirectional data | bidi |
| 5 | RST | chip enable (in, active HIGH) | input |

## Chip vs module
The DS1302 **chip** is 8-pin: VCC1 (backup), VCC2 (main), GND, SCLK, I/O, CE/RST,
X1, X2 (32.768 kHz crystal). The **module** carries the crystal + coin-cell holder
onboard and breaks out only the 5 useful pins above.
