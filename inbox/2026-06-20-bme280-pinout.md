# BME280 environmental sensor — verification note

Added `core:bme280` to `@protopulse/parts` as a **verified** part — the digital
(I²C) complement to the analog TMP36. Provenance trail per the Hardware &
Component Verification Protocol (vault checked — no prior note — then datasheet).

## Part
- **MPN:** BME280
- **Manufacturer:** Bosch Sensortec
- **Datasheet:** https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bme280-ds002.pdf
- **Package:** LGA-8, 2.5 × 2.5 × 0.93 mm (metal lid)
- **Class:** environmental sensor (modeled `class: 'ic'`, refPrefix `U`)

## Pinout — LGA-8 (numbered clockwise from top)
| Pin | Name | I²C role | Electrical type (ERC) |
|----:|------|----------|-----------------------|
| 1 | GND   | ground            | power_in |
| 2 | CSB   | tie to VDDIO → I²C | input   |
| 3 | SDI   | **SDA**           | bidi    |
| 4 | SCK   | **SCL**           | input   |
| 5 | SDO   | addr select (GND→0x76, VDDIO→0x77); SPI MISO | bidi |
| 6 | VDDIO | I/O supply        | power_in |
| 7 | GND   | ground            | power_in |
| 8 | VDD   | core supply       | power_in |

## Interface / electrical
- **Interface select:** CSB → VDDIO = I²C; CSB pulled low = SPI.
- **I²C address:** 0x77 default (SDO high/VDDIO); 0x76 with SDO → GND.
- **I²C speed:** up to 3.4 MHz (fast-mode plus / HS).
- **Supply:** VDD 1.71–3.6 V, VDDIO 1.2–3.6 V; ~714 µA during combined measurement.
- Measures temperature, humidity, and barometric pressure.
