# L298N dual H-bridge motor driver — verification note

Added `core:l298n` to `@protopulse/parts`. Pinout **web-verified** — NOT taken from
Tyler's shared `docs/parts-components-ect.md`. Second motor-driver part (after
ULN2003); this one is a full dual H-bridge for DC motors / one bipolar stepper.

## Part
- **MPN:** L298N (board uses an ST L298 dual full-bridge + 78M05 5 V regulator)
- **Datasheet:** https://www.st.com/resource/en/datasheet/l298.pdf
- **Function:** 2 DC motors (or 1 bipolar stepper); Vs 2.5–46 V, 2 A/channel
  continuous (3 A peak), PWM speed control.
- **Class:** modeled `class: 'ic'`, refPrefix `U`

## Pinout — modeled module pins (verified)
| Pin | Name | Role | Electrical type (ERC) |
|----:|------|------|-----------------------|
| 1 | +12V | Vs motor supply 2.5–46 V | power_in |
| 2 | GND | ground | power_in |
| 3 | +5V | logic rail (see dual-role note) | power_in |
| 4 | ENA | bridge-A enable / PWM | input |
| 5 | IN1 | bridge-A direction | input |
| 6 | IN2 | bridge-A direction | input |
| 7 | IN3 | bridge-B direction | input |
| 8 | IN4 | bridge-B direction | input |
| 9 | ENB | bridge-B enable / PWM | input |
| 10 | OUT1 | bridge-A output | output |
| 11 | OUT2 | bridge-A output | output |
| 12 | OUT3 | bridge-B output | output |
| 13 | OUT4 | bridge-B output | output |

## +5V dual-role note
The +5V pin is the onboard **78M05 regulator OUTPUT** when the 5V-enable jumper is
fitted (the usual case — you can power your MCU from it), or a **5 V logic INPUT**
when the jumper is removed (required when Vs > 12 V, since the 78M05 input is then
out of spec). Modeled as a power rail pin (`power_in`) with the dual role documented,
matching the library's conservative VCC convention.

## Verification
- Web sources: ST L298 datasheet, components101 L298N module page, etechnophiles
