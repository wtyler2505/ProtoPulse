# HC-SR04 ultrasonic distance sensor — verification note

Added `core:hc-sr04` to `@protopulse/parts`. The iconic 4-pin ultrasonic ranging module
(Tyler owns it — "Ultrasonic Distance Sensor (HC-SR04)" in the component log). Pinout
**web-verified** against the manufacturer datasheet + multiple references.

## Part
- **MPN:** HC-SR04 (ElecFreaks original design)
- **Class:** `ic`, refPrefix **U** (module). 4 pins. Footprint deferred.

## Pinout — 4-pin header, left → right
`VCC, TRIG, ECHO, GND`. 5 V supply, 2–400 cm range, 40 kHz burst, ±3 mm.

## ERC modeling
- **VCC, GND → power_in** (5 V supply).
- **TRIG → input** — the MCU drives a 10 µs high pulse to start a measurement.
- **ECHO → output** — the module drives this pin high for a duration equal to the
  ultrasonic round-trip time (the MCU measures the pulse width).

This matches the established convention: MCU-driven control lines = input, sensor-driven
signal outputs = output.
