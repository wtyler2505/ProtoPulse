# DS3231 (ZS-042) RTC module — verification note

Added `core:ds3231` to `@protopulse/parts`. Pinout **web-verified** — NOT taken
from Tyler's shared `docs/parts-components-ect.md`. Companion to the DS1302 added
the same day; the contrast is the point: **DS1302 is 3-wire serial, DS3231 is I²C.**

## Part
- **MPN:** DS3231 (Maxim / Analog Devices "Extremely Accurate I²C RTC/TCXO")
- **Module:** ZS-042 board (also carries an AT24C32 EEPROM at 0x57 on the same bus)
- **Datasheet:** https://www.analog.com/media/en/technical-documentation/data-sheets/ds3231.pdf
- **Function:** TCXO-compensated RTC, ±2 ppm 0–40 °C, alarms, temp sensor
- **Class:** modeled `class: 'ic'`, refPrefix `U`

## Interface — I²C (addr 0x68)
SCL = clock in, SDA = bidirectional data. SQW (square-wave / alarm interrupt) and
32K (32.768 kHz) are both **open-drain outputs** requiring external pull-ups.

## Pinout — ZS-042 6-pin header (verified names)
| Pin | Name | Role | Electrical type (ERC) |
|----:|------|------|-----------------------|
| 1 | 32K | 32.768 kHz output (open-drain) | output |
| 2 | SQW | square-wave / alarm interrupt (open-drain) | output |
| 3 | SCL | I²C clock (in) | input |
| 4 | SDA | I²C data | bidi |
| 5 | VCC | 3.3–5.5 V | power_in |
| 6 | GND | ground | power_in |

## Header-order caveat (resolved)
The ZS-042 has **two 6-pin headers on opposite edges** and the silk order is
**board-revision-dependent** — components101/lastminuteengineers diagrams read
`32K, SQW, SCL, SDA, VCC, GND` while Cirkit Designer's table reads the exact
reverse (`VCC, GND, SDA, SCL, SQW, 32K`, i.e. numbered from the other end). The pin
**names and functions are fixed**; only the numbering end differs. We number 1–6 in
the dominant published order and document the caveat rather than assert a single
physical end as canonical.
