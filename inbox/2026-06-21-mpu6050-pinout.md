## Pinout — GY-521 module header (verified order)
| Pin | Name | Role | Electrical type (ERC) |
|----:|------|------|-----------------------|
| 1 | VCC | supply (module 3–5 V via onboard 3.3 V reg) | power_in |
| 2 | GND | ground | power_in |
| 3 | SCL | I²C clock (in) | input |
| 4 | SDA | I²C data | bidi |
| 5 | XDA | auxiliary I²C master data | bidi |
| 6 | XCL | auxiliary I²C master clock | output |
| 7 | AD0 | address select (low→0x68, high→0x69) | input |
| 8 | INT | data-ready / motion interrupt (out) | output |

## Interface / electrical
- **I²C address:** 0x68 default (AD0 low), 0x69 (AD0 high).
- **Aux bus:** XDA/XCL are an auxiliary I²C *master* for chaining a slave (e.g. a magnetometer) through the MPU-6050.
- **Supply:** MPU-6050 chip is 2.375–3.46 V; the GY-521 module adds a regulator so VCC tolerates ~3–5 V. ~3.9 mA accel+gyro on.
