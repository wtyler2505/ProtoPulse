# TB6612FNG dual motor driver — verification note

Added `core:tb6612fng` to `@protopulse/parts`. Pinout **web-verified** — NOT taken
from Tyler's shared `docs/parts-components-ect.md`. Closes out the Tier-1 motor-driver
set (with ULN2003 + L298N); the TB6612FNG is the efficient MOSFET-H-bridge alternative
to the bipolar L298N.

## Part
- **MPN:** TB6612FNG (Toshiba dual H-bridge, MOSFET)
- **Datasheet:** https://cdn.sparkfun.com/datasheets/Robotics/TB6612FNG.pdf
- **Function:** 2 DC motors, 1.2 A continuous / 3.2 A peak per channel, PWM to 100 kHz.
- **Class:** modeled `class: 'ic'`, refPrefix `U`

## Pinout — modeled 14 unique signals (verified)
| Pin | Name | Role | Electrical type (ERC) |
|----:|------|------|-----------------------|
| 1 | VM | motor supply ≤15 V | power_in |
| 2 | VCC | logic 2.7–5.5 V | power_in |
| 3 | GND | ground | power_in |
| 4 | AO1 | motor A output | output |
| 5 | AO2 | motor A output | output |
| 6 | BO1 | motor B output | output |
| 7 | BO2 | motor B output | output |
| 8 | PWMA | motor A speed (PWM) | input |
| 9 | AIN1 | motor A direction | input |
| 10 | AIN2 | motor A direction | input |
| 11 | STBY | standby, active-low (high = enable) | input |
| 12 | BIN1 | motor B direction | input |
| 13 | BIN2 | motor B direction | input |
| 14 | PWMB | motor B speed (PWM) | input |

## Control logic
Per motor: xIN1/xIN2 set one of four modes (CW / CCW / short-brake / stop), PWMx sets
speed. STBY must be pulled HIGH to take the chip out of standby. The SparkFun breakout
exposes all pins across two 0.1" headers (control side vs motor/power side); GND
appears on both physically but is one net (modeled once).
