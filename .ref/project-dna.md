## Tech Stack

- **Runtime**: Node.js, Express 5 (tsx dev / esbuild prod) — npm workspaces (`packages/*`, `tools/golden`), root package `rest-express`
- **Frontend**: React 19 + Vite 7 SPA (legacy `client/`) AND a WebGL2 editor (`@protopulse/app`, port 5174)
- **Language**: TypeScript 5.6 — 2,353 TS files, ~648k LOC of code (scc)
- **Data**: PostgreSQL via Drizzle ORM + Zod — `shared/schema.ts` defines 47 pgTable tables
- **AI**: legacy dual-provider (`@anthropic-ai/sdk` + `@google/genai`, 113 tool actions) AND `@protopulse/ai` (provider-agnostic crew runtime: Draftsman/Analyst/Professor/Router/Architect/Buyer)
- **Testing**: Vitest 4 + happy-dom + Testing Library (822 test files repo-wide; 1,517 engine tests), Playwright e2e
- **Other**: Tailwind v4 + shadcn/ui (legacy), Tauri v2 scripts, ngspice-WASM (`@protopulse/sim`), avr8js/rp2040js + from-scratch ESP32-S3 Xtensa LX7 (`@protopulse/emu`, through TWAI/CAN slice 108)

## Architecture in 30 Seconds

Browser EDA platform — three coexisting layers in one repo:
1. **Legacy shipping app** — `client/` (React SPA, 35+ views switched by `ViewMode`), `server/` (Express monolith: 37 route modules, 13 circuit routers, 22 AI-tool modules), `shared/` (schema, DRC engine, diff/parts utilities). State flows through one `ProjectProvider` context + React Query.
2. **The engine redesign** (`packages/*`, 16 `@protopulse/*` workspaces) — one canonical design graph; every mutation is a typed op; **the design IS its op-log**, the graph a materialized view. That buys byte-exact exports, exact undo, O(1) branches, three-way merge, time-lapse replay, live sync. graph → parts/erc/export/drc/route/sim/emu/cosim/review/relay/renderer/ai/cli/content → app. `tools/golden/` holds the export contracts. ROADMAP: v0.1–v0.4 ✅ (June 2026), v0.5 Bridge + v0.6 World 🔨; legacy migrates onto the engine between v0.6 and v0.7.
3. **Ars Contexta vault** — `knowledge/`, `inbox/`, `ops/`, `self/` markdown knowledge system; the repo doubles as an Obsidian vault.

## Non-Obvious Conventions

- **Golden files are contracts** — `tools/golden/` op-logs → byte-exact exports; re-freeze ONLY deliberately via `tools/golden/update-golden.ts`, review like an API change
- **Integer nanometers everywhere** in `packages/*` — `MM = 1_000_000`, grid 1.27mm; floats break diff determinism and zod rejects them at the boundary
- **Vault pipeline** — never write directly to `knowledge/`; everything routes `inbox/` → /extract; hardware facts verified against datasheets, never invented
- **`AGENTS.md` is the single agent config**; an auto-commit hook creates "Auto: N files" commits constantly — filter them out of any git-log analysis

## Architectural Decisions

- **Op-log-as-source-of-truth graph** (`@protopulse/graph`): one mechanism yields determinism, undo (inverse ops), branches-as-pointers, merge-conflicts-as-data — the whole vision rests on it
- **Engine built alongside the legacy app, not rewritten in place**: `client/server/shared` keeps shipping untouched; proven pieces port in deliberately; migration is an explicit ROADMAP milestone
- **Packages ship TypeScript source** (`main: ./src/index.ts`) — Vite/Vitest/tsx consume it directly; only the CLI builds a bundle

## Gotchas

- `npm run check` needs `--max-old-space-size=16384`; `npm test` needs 8GB — the legacy codebase is huge
- `docs/vision/*` is a **frozen spec** — never edit in place; deviations become ADRs in `docs/adr/`
- `.env` is untracked/gitignored — never read or commit it
- Two dev servers: legacy on :5000 (`npm run dev`), new editor on :5174 (`npm run -w @protopulse/app dev`)
