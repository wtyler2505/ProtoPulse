## Architecture in 30 Seconds

Browser EDA platform — three coexisting layers in one repo:
1. **Legacy shipping app** — `client/` (React SPA, **36 ViewMode views**, 118 view components), `server/` (Express monolith: **37 route modules, 15 circuit routers, 30 AI-tool modules**), `shared/` (47-table schema, DRC engine, diff/parts utilities). State flows through one `ProjectProvider` (nests 8 domain providers) + React Query.
2. **The engine redesign** (`packages/*`, **16 `@protopulse/*` workspaces**) — one canonical design graph; every mutation is a typed op; **the design IS its op-log**, the graph a materialized view. That buys byte-exact exports, exact undo, O(1) branches, three-way merge, time-lapse replay, live sync. graph → parts/erc/export/drc/route/sim/emu/cosim/review/relay/renderer/ai/cli/content → app. `tools/golden/` holds the export contracts. ROADMAP: v0.1–v0.4 ✅; v0.5 Bridge (emu/cosim — I2C+SPI device co-sim now closed-loop) + v0.6 World 🔨; legacy migrates onto the engine between v0.6 and v0.7.
3. **Ars Contexta vault** — `knowledge/`, `inbox/`, `ops/`, `self/` markdown knowledge system; the repo doubles as an Obsidian vault. PP-NLM (NotebookLM) layer is Codex-owned.

## Non-Obvious Conventions

- **Golden files are contracts** — `tools/golden/` op-logs → byte-exact exports; re-freeze ONLY deliberately via `tools/golden/update-golden.ts`, review like an API change
- **Integer nanometers everywhere** in `packages/*` — `MM = 1_000_000`, grid 1.27mm; floats break diff determinism and zod rejects them at the boundary
- **Vault pipeline** — never write directly to `knowledge/`; everything routes `inbox/` → /extract; hardware facts verified against datasheets, never invented (`hardware-enforcement.sh` hook)
- **`AGENTS.md` is the single agent config** (CLAUDE.md/GEMINI.md/.cursorrules/.windsurfrules/.github/copilot-instructions.md are symlinks); an auto-commit hook creates "Auto: N files" commits constantly — filter them out of any git-log analysis
- **Jurisdiction**: Claude's lane = `client/ server/ shared/ packages/` + AI config (AGENTS.md, .ref, .claude/skills+hooks). **PP-NLM is Codex-owned** (`data/pp-nlm/**`, `scripts/pp-nlm/**`, `pp-*` skills/commands/hooks, `docs/notebooklm.md`) — observe, never edit.

## Architectural Decisions

- **Op-log-as-source-of-truth graph** (`@protopulse/graph`): one mechanism yields determinism, undo (inverse ops), branches-as-pointers, merge-conflicts-as-data — the whole vision rests on it
- **Engine built alongside the legacy app, not rewritten in place**: `client/server/shared` keeps shipping untouched (frozen); proven pieces port in deliberately; migration is an explicit ROADMAP milestone
- **Packages ship TypeScript source** (`main: ./src/index.ts`) — Vite/Vitest/tsx consume it directly; only the CLI builds a bundle
- **Engine AI is provider-agnostic** (`LlmProvider` interface, `AnthropicProvider` + `FakeProvider`); the Router classifies intent and dispatches to focused crews rather than one mega-agent

## Gotchas

- `npm run check` needs `--max-old-space-size=16384`; `npm test` needs ~8GB — the legacy codebase is huge. **`earlyoom` SIGKILLs the biggest-RSS process on this ~7GB box** — heavy builds/test runs die with code 143/137. Do NOT raise `--max-old-space-size` to fix it (trips earlyoom sooner). A PreToolUse hook forces test runs to background.
- **Test counts: enumerate, don't execute** — `vitest list` is sandbox-blocked on `.env`; use the static line-anchored count (method below) for headline numbers.
- `docs/vision/*` is a **frozen spec** — never edit in place; deviations become ADRs in `docs/adr/`
- `.env` is untracked/gitignored — never read or commit it (use desktop-commander for any sensitive-file read)
- Two dev servers: legacy on :5000 (`npm run dev`), new editor on :5174 (`npm run -w @protopulse/app dev`)
- ROADMAP status legend is honest by policy — trust it over READMEs elsewhere
