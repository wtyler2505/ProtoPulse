## Exported API — key engine entry points

### `@protopulse/graph` — `packages/graph/src/index.ts`
- Model: `DesignGraph`, `Component`, `Net`, `Port`, `Constraint`, `GeometryMap`; `OpBody`/`OpEnvelope` (50+ op codes)
- Mutations: `applyOp(graph, op)` → `ApplyResult`; `materialize(opLog, opts)` → `MaterializeResult`
- Branch/merge: `diff(a,b)` → `GraphDelta`; `threeWayMerge(base,ours,theirs)` → `MergeResult`; `resolveConflict`; `BranchLog`/`BranchRef`/`MAIN_BRANCH`
- Utilities: `validateGraph` (5 invariants), `invertOp` (undo), `parseValue` (units), `encodeBundle`/`decodeBundle`/`designBundleSchema` (`.ppx.json`)

### `@protopulse/ai` — `packages/ai/src/index.ts`
- Registry: `ToolRegistry`, `zodToJsonSchema`, `DispatchResult`/`ToolCtx`/`ToolResult`
- Loop + crew: `runAgentLoop`; `runDraftsman`/`runAnalyst`/`runProfessor`/`runRouter`/`runArchitect`/`runBuyer` + per-persona `create*Registry`
- Context: `assembleContext(graph, budget)`, `CONTEXT_BUDGETS`, `designDigest`
- Providers: `AnthropicProvider`, `FakeProvider`; types `LlmProvider`/`AgentEvent`/`ProviderMessage`/`LlmTurn`

### `@protopulse/emu` — `packages/emu/src/index.ts`
- Cores: `Atmega328pCore`, `Rp2040Core`, `Esp32s3Core` (Xtensa LX7; dual SAR ADC, TIMG0/1, I2C, SPI, TWAI/CAN, PCNT, MCPWM, crypto SHA/AES/RSA/HMAC/DS)
- Devices: I2C `Bme280State`/`mpu6050`/`ds3231` + `I2C_DEVICES_BY_PART_ID`; SPI `rc522` + `SPI_DEVICES_BY_PART_ID`
- Contract/utils: `McuCore`, `PinEvent`, `AdcSampler`, `parseIntelHex`, `assemble` (test rig)

### `@protopulse/cosim` — `packages/cosim/src/index.ts`
- Open-loop: `runCosimWindow` → `CosimResult`; `pinEventsToPwl`, `bindingCard`
- Closed-loop: `runCosimClosedLoop` → `ClosedLoopResult`; `comparatorStep` (Schmitt), `interpolateAt`; `i2cDevicesFromGraph`/`spiDevicesFromGraph` auto-resolve placed parts → device bindings

### `@protopulse/cli` — `packages/cli/src/index.ts`
- commander.js: `check <design>` (materialize+ERC), `export <design>`, `import-legacy <snapshot>`. Exit 0/1/2.

# PART 2 — THE LEGACY APP (`client/ server/ shared/`)

## `server/` — Express 5 monolith

- **Bootstrap**: `server/index.ts` (Helmet CSP + nonce, auth, rate-limit, metrics, collaboration WS attach, static serving, calls `registerRoutes()`). No exports — side effects only.
- **Domain routes** (`server/routes/`, **37 modules** + barrel `server/routes.ts`): each exports `register<Domain>Routes(app)`. Covers auth, projects, architecture, components/lifecycle, chat/chat-branches, history, validation, exports/export-step, arduino, bom-*, comments, backup/project-io, jobs/batch, admin, ordering/supply-chain, boards/pcb-zones/spice-models, knowledge-vault, rag, agent, parts, firmware-runtime, settings/design-preferences, embed. Barrel re-exports `HttpError`/`asyncHandler`/`parseIdParam`/`payloadLimit`/`paginationSchema`.
- **Circuit routes** (`server/circuit-routes/`, **15 files → 13 registered routers** + barrel): `register<Feature>Routes(app, storage: IStorage)` — explicit storage DI. designs, instances, nets, wires, vias, expansion, netlist, hierarchy, simulations, autoroute, imports, exports, apply-code.
- **AI tools** (`server/ai-tools/`, **30 modules** + barrel `server/ai-tools.ts`): consumed by `server/ai.ts` (Genkit flows, dual-provider Claude→Gemini fallback, ~113 tool actions). Circuit/firmware/procurement/export tool families. `server/circuit-ai.ts`, `server/genkit.ts`, `server/component-ai.ts` adjacent.
- **Support**: `auth.ts`, `db.ts` (Drizzle/PG), `storage.ts` (`IStorage`), `cache.ts`, `metrics.ts`, `audit-log.ts`, `collaboration.ts` (Y.js CRDT WS), `job-queue.ts`, `logger.ts` (Pino), `env.ts` (zod), `static.ts`, `api-docs.ts`.

## `client/` — React 19 SPA

# PART 3 — CONTRACTS & GOTCHAS

- **`tools/golden/`** — 5 reference designs (led-resistor, traffic-light-555, routed-led, …) → byte-exact expected exports. Re-freeze ONLY via `tools/golden/update-golden.ts`; review like an API change.
- **Integer nanometers** in `packages/*` (`MM = 1_000_000`); floats rejected at the zod boundary.
- **No root build** — packages ship TS source (`main: ./src/index.ts`); only `cli` bundles (esbuild).
- **earlyoom** kills heavy builds/tests on the ~7GB box; test runs forced to background by a PreToolUse hook; enumerate test counts (don't execute).
- **Jurisdiction**: PP-NLM (`data/pp-nlm/**`, `scripts/pp-nlm/**`, `pp-*` skills/commands, `docs/notebooklm.md`) is Codex-owned — observe, never edit.
