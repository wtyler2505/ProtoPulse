**Notes for implementers:**
- P0 items (esp 01-04) must be resolved before claiming the 3D View is usable for "real hardware work".
- After wiring data (UI-3D-01), the perf (04) and layer (02) issues become immediately visible and will block users.
- Follow ux-contract strictly: make panels collapsible, scene scale, states clear.
- Consider deprecating pure CSS path in favor of the existing (but unused) WebGL engine for scale.
- Update self-improvement-log.md and re-run inspector after fixes.
